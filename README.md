# 📝 Interactive To-Do List App with Progress Tracking

A sleek, responsive, and highly interactive To-Do List web application built using clean semantic HTML5, modern CSS Layouts, and Vanilla JavaScript. The application features live progress tracking, visual empty states, fully functional task editing/deletion, completion tracking, and celebration animations upon task completion.

---

## ✨ Features

*   **Add & Track Tasks:** Easily add new tasks by clicking the add button or pressing the `Enter` key.
*   **Dynamic Progress Tracking:** A visual progress bar and numeric counter update in real-time as you add, complete, or delete tasks.
*   **Inline Editing:** Change task descriptions on the fly—clicking the edit button moves the task back into the input field for quick adjustments.
*   **Task Completion:** Checkboxes let you cross off completed items, changing their status and locking edits on finished items.
*   **Dynamic Empty State:** Automatically shrinks the workspace and displays an empty state image when no tasks exist.
*   **Completion Celebration:** Integrates the `canvas-confetti` library to launch an absolute burst of confetti when you successfully cross off all the tasks on your list.
*   *   **Authentication for User login:** Register and sign in to your own account to access your own task and categories

---

## 🛠️ Technology Stack

*   **HTML5:** Semantic markup structure.
*   **CSS3:** Flexbox layouts, dynamic sizing transitions, and status-based conditional styling.
*   **JavaScript (ES6+):** Complete DOM manipulation, customized event listeners, conditional operators, and state handling.
*   **External Libraries:** 
    *   [Canvas-Confetti](https://github.com/catdad/canvas-confetti) for celebration effects.
    *   [FontAwesome](https://fontawesome.com/) for UI control icons.
